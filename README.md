# Hi Mose

دستیار صوتی شخصی اندروید برای گفت‌وگو و اجرای فرمان‌های مجاز گوشی.

## قابلیت‌های نسخه نخست
- فعال‌سازی با دکمه و شنیدن عبارت «Hi Mose» در برنامه
- گفت‌وگوی صوتی فارسی
- بازکردن برنامه‌ها، شماره‌گیر و پیامک با تأیید کاربر
- ساخت خودکار APK با GitHub Actions

> کنترل تماس، پیام و برنامه‌ها فقط با مجوزهای شفاف اندروید انجام می‌شود.
