# ELAT Android Native

Development branch for the ELAT.ir Android application.

## Target stack
- Kotlin
- Jetpack Compose
- Clean Architecture
- MVVM
- Hilt
- Firebase AI Logic + Gemini

## Product scope
- Three reading layers: 30 sec / 2 min / 5+ min
- Ask ELAT grounded in ELAT.ir content
- Five analytical reactions
- Story poster generator
- Morning analysis radio + weekly podcast
- Full RTL, Persian digits and Jalali date
- Release APK size target: under 25 MiB

Branch: `elat-native-v1`

The existing `main` branch has not been modified.
